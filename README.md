# Cat and Bird

A triangular HTML and CSS interpretation of Paul Klee's *Cat and Bird* (1928).

Open `index.html` in a browser. Keep `textured-paper.png` in the same folder.

## References

- Painting: [Paul Klee, Cat and Bird, MoMA](https://www.moma.org/collection/works/79456)
- Texture: [Textured Paper](https://www.transparenttextures.com/textured-paper.html), by Stephen Gilbert, originally published on Subtle Patterns.
